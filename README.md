# 喜茶式微动态视频提示词 Skill

这是一个用于生成 `Seedance 2.5` 图生视频提示词的中文 Skill。它以用户上传的海报图为逐帧静止基准，只让黑色手绘涂鸦小人进行幅度很小的动作，生成 3–5 秒、可自然循环的极简治愈系微动态海报提示词。

本项目是私有仓库，仅供获得 GitHub 访问权限的账号使用；它不是喜茶官方工具，也不包含喜茶 Logo、品牌素材或官方提示词。

## 能力

- 锁定海报主体、手写文案、背景、排版、投影、留白比例、裁切和整体构图。
- 只允许原图中已有的黑色涂鸦小人运动，并根据小人的既有姿态和主体功能设计轻微动作。
- 固定镜头为 `fixed/static shot`，禁止推拉、摇移、旋转、切镜和改变裁切。
- 使用手绘定格动画（`stop-motion / frame-by-frame`）质感，避免 3D 插值、夸张弹跳和大幅形变。
- 通过首尾姿态闭合、避免突然重置，生成适合循环播放的微动态方案。
- 只有文字时，也能先把文字解释为一张静态海报设计说明；如果目标平台只支持图生视频，会明确提醒先提供海报图。

## 安装

先确认当前 GitHub 账号对私有仓库有访问权限，然后执行：

```bash
npx skills add cylqwe7855-alt/heicha-micro-motion-video -g -a codex -y
```

也可以手动克隆后，将 `heicha-micro-motion-video` 文件夹放入对应的 Skill 目录：

```bash
git clone https://github.com/cylqwe7855-alt/heicha-micro-motion-video.git
```

## 使用

安装后可以直接说：

> 使用我上传的海报图，做一个 4 秒可循环微动态视频，只让黑色小人轻轻擦拭主体。

或者：

> 根据这段海报描述生成 Seedance 2.5 微动态视频提示词，主体和文字必须静止。

默认交付一段完整的 `Seedance 2.5` 提示词和一句素材使用说明。如果用户明确要求且当前平台提供视频生成能力，调用方可以在整理提示词后直接生成视频；否则交付提示词，不虚构生成结果。
